# Спутниковая группировка для связи северных пунктов

Домен сервиса «Аврора»: геометрия орбит, видимость и маршрут до шлюза, показатели доступности и устойчивости к отказам. Термины совпадают с постановкой кейса и полями схемы `cosmo-A-1.0`, чтобы код, интерфейс и отчёт говорили на одном языке.

## Language

**Сценарий**:
JSON-файл схемы `cosmo-A-1.0` с параметрами среды, составом группировки, наземными пунктами и событиями недоступности. В коде — объект `scenario`; исходный вариант хранится как `base`.
_Avoid_: проект, конфиг-файл, датасет

**Конфигурация**:
Текущее (возможно изменённое) состояние сценария в интерфейсе: этап, плоскости, отказы, пункты. То, что сохраняют как вариант и сравнивают.
_Avoid_: настройки, сетап

**Плоскость (plane)**:
Орбитальная плоскость с `id`, `raan_deg` и `phase_deg`; спутники распределены по плоскостям. В кейсе их три (P1–P3) по 16 аппаратов.
_Avoid_: орбита (это траектория одного аппарата), кольцо

**RAAN**:
Долгота восходящего узла плоскости, градусы `[0, 360)`. Поворачивает плоскость вокруг оси Земли.
_Avoid_: азимут, ориентация

**Фазирование (phase_deg)**:
Общий сдвиг всех аппаратов плоскости вдоль орбиты, градусы. Имеет смысл по модулю шага слотов (22.5° в кейсе).
_Avoid_: фаза (без уточнения), смещение

**Слот (slot_deg)**:
Положение аппарата внутри плоскости вдоль орбиты. Соседние слоты через 22.5° — единственная дистанция, на которой в кейсе работает ISL внутри плоскости (≈2700 км < 3000 км).
_Avoid_: позиция, номер

**Очередь запуска (launch_batch)**:
Номер запуска, которым аппарат выводится: целое ≥ 1 (в кейсе — 1, 2, 3). Число и размер очередей задаёт проектировщик; раскладка «плоскость за плоскостью» или «вперемешку по плоскостям».
_Avoid_: партия, волна

**Этап развёртывания (launch_stage)**:
Сколько очередей уже считаются запущенными (в кейсе 1 → 16 КА, 2 → 32, 3 → 48). Аппарат активен, если `launch_batch ≤ launch_stage` и он не в отказе. Кнопок этапов столько, сколько очередей.
_Avoid_: стадия, фаза развёртывания

**Наклонение плоскости**:
Угол плоскости к экватору. Общее задаётся в `environment.inclination_deg`; плоскость может иметь своё (`planes[].inclination_deg`) — «разные оси» группировки.
_Avoid_: ось (без уточнения), наклон

**Walker T/P/F**:
Стандартная схема группировки: T аппаратов поровну в P плоскостях, F — межплоскостное фазирование (сдвиг фазы соседней плоскости на F·360°/T). Веер RAAN 360° — Delta, 180° — Star. Кейс = 48/3/1, веер 180°.
_Avoid_: созвездие, паттерн

**Конструктор группировки**:
Форма, которая заменяет состав группировки сгенерированным Walker-проектом с заданным числом очередей.
_Avoid_: генератор, билдер

**Подбор проекта**:
Перебор Walker-конфигураций под заданные пункты: фронт «число аппаратов ↔ доступность худшего пункта», минимальная группировка, достигающая цели, показатели первой очереди.
_Avoid_: оптимизация группировки (это про RAAN/фазу существующей), design search

**Активный аппарат**:
Спутник, который в данный момент запущен и не находится в периоде недоступности. Только активные участвуют в ISL и видимости.
_Avoid_: живой, рабочий, включённый

**Период недоступности (outage)**:
Интервал `[start_s, end_s)`, в течение которого спутник (`failures`) или шлюз (`gateway_outages`) исключён из сети.
_Avoid_: авария, даунтайм, поломка

**Отказ**:
Период недоступности спутника; в интерфейсе — красный маркер и крест. В анализе «отказ на весь горизонт» = `[0, horizon_s)`.
_Avoid_: сбой, выход из строя

**Клиентский пункт (client)**:
Наземная точка, для которой считается связь. Не ретранслирует трафик.
_Avoid_: терминал, абонент, станция

**Шлюз (gateway)**:
Наземная станция выхода в наземную сеть; маршрут обязан заканчиваться на аппарате, видимом со шлюза. Может быть несколько.
_Avoid_: гейтвей, базовая станция, наземка

**Наземный пункт (ground site)**:
Общее имя клиентского пункта и шлюза; список `ground_sites`.
_Avoid_: точка, объект

**Видимость**:
Аппарат виден с пункта, если угол возвышения ≥ `min_elevation_deg` (10°) и не ниже маски горизонта в своём азимуте. Считается для активных аппаратов.
_Avoid_: покрытие (это агрегат по времени/территории), контакт (без уточнения)

**Маска горизонта (horizon_mask)**:
Угол закрытия неба рельефом или застройкой по секторам азимута (36 по 10°, от севера по часовой). Необязательное поле пункта; без него действует правило кейса. Источники: местность (пресет), рельеф DEM, своя.
_Avoid_: профиль горизонта, тень рельефа, obstruction

**Местность (terrain)**:
Именованный пресет маски горизонта: открытая, посёлок, город, плотный город, горная долина, антенна на крыше — задаётся высотой застройки и расстоянием до антенны. «Рельеф DEM» — маска, посчитанная по цифровой модели рельефа.
_Avoid_: тип застройки, окружение

**Азимут и возвышение**:
Направление на аппарат из пункта в местной системе «восток–север–зенит»: азимут от севера по часовой 0…360°, возвышение над горизонтом. Функция `lookAngles()`.
_Avoid_: пеленг, угол места (в интерфейсе)

**ISL (межспутниковая связь)**:
Ребро между двумя активными аппаратами: расстояние < `isl_range_km` и отрезок не пересекает Землю.
_Avoid_: линк, канал, соединение

**Снимок сети (snapshot)**:
Состояние на один шаг расчёта: положения, активность, рёбра ISL, видимость с каждого пункта, признак тени. Функция `snapshot(s, t)`.
_Avoid_: кадр, состояние (без уточнения)

**Маршрут**:
Последовательность активных аппаратов от клиентского пункта до шлюза по существующим на данном шаге связям; ищется BFS по числу хопов.
_Avoid_: путь, трасса, роут

**Липкий маршрут**:
Правило обновления: прежний маршрут сохраняется, пока живы все его звенья; новый ищется только при разрыве. Так считаются переключения.
_Avoid_: кеш маршрута, удержание

**Переход**:
Ребро маршрута. Число переходов = число рёбер, включая две наземные линии (аппаратов + 1); при отсутствии маршрута значения нет. Так определено в «Описании данных».
_Avoid_: хоп, прыжок, узел

**Переключение маршрута (handover)**:
Смена цепочки аппаратов между соседними шагами, когда прежний маршрут перестал существовать.
_Avoid_: хендовер (в интерфейсе), перестроение

**Причина отсутствия маршрута**:
Одно из четырёх: нет видимого спутника над пунктом (`no_sat`), разрыв межспутниковой сети (`net_split`), нет контакта со шлюзом (`no_gw_contact`), шлюз недоступен (`gw_offline`).
_Avoid_: ошибка, статус

**Доступность**:
Доля шагов расчётной сетки, на которых у пункта есть маршрут. Основной показатель; цель — `target_availability` (0.9) для каждого клиентского пункта.
_Avoid_: аптайм, покрытие, надёжность

**Перерыв**:
Непрерывная серия шагов без маршрута. Максимальный перерыв — самый длинный за горизонт, в минутах.
_Avoid_: пауза, разрыв (это про сеть), простой

**Горизонт и шаг расчёта**:
`horizon_s` (86400 с) и `step_s` (120 с) задают сетку отсчётов 0, 120, …, 86 280 — правый конец не включается, всего 720 отсчётов; каждый представляет интервал длиной шаг. На ней считаются все показатели. Грубая сетка `stepMul` используется только внутри переборов.
_Avoid_: интервал, тик

**Задержка**:
Односторонняя задержка сигнала по длине маршрута (пункт → аппараты → шлюз) со скоростью света, мс. Без бортовой обработки.
_Avoid_: пинг, RTT, латентность

**Вариант**:
Сохранённая конфигурация вместе с её сводкой показателей и описанием отличий от файла; единица сравнения.
_Avoid_: версия, сохранение, снапшот

**Сравнение**:
Таблица вариантов: параметры (отличия подсвечены), показатели по пунктам с дельтами к первому столбцу, рекомендация по оценке.
_Avoid_: диф, бенчмарк

**Оценка конфигурации (score)**:
Скаляр для оптимизаторов: худший пункт × 1000 + средняя доступность × 100 + видимость × 10 − перерывы − переходы. Лексикографическая по смыслу.
_Avoid_: рейтинг, метрика

**Покрытие**:
Доступность, посчитанная для сетки точек 55–85° с.ш.; карта на глобусе и доля площади с доступностью ≥ цели.
_Avoid_: зона обслуживания, footprint

**План развёртывания**:
Показатели по этапам 1→2→3 с шагом три месяца между запусками.
_Avoid_: роадмап, график запусков

**Запас прочности**:
Целое 0–2: сколько одновременных отказов любых аппаратов группировка выдерживает, не опускаясь ниже цели (по матрице N-1/N-2).
_Avoid_: резервирование, надёжность, k-устойчивость

**Матрица N-1 / N-2**:
Минимальная доступность при отказе каждого аппарата (диагональ) и каждой пары (остальные клетки) на весь горизонт.
_Avoid_: тепловая карта отказов

**Уязвимый аппарат**:
Спутник, отказ которого сильнее всего снижает доступность худшего пункта.
_Avoid_: критичный узел, слабое звено

**Резервный аппарат (SP)**:
Дополнительный спутник в свободном слоте между соседями плоскости, добавляемый для повышения устойчивости; id `SP1`, `SP2`…
_Avoid_: запаска, spare

**Тень (eclipse)**:
Аппарат в цилиндрической тени Земли относительно условного направления на Солнце (`environment.sun_eci`). Режим `eclipse_isl_off` запрещает таким аппаратам ретрансляцию.
_Avoid_: ночь, затмение

**Результат (cosmo-A-result-1.0)**:
Выгружаемый файл: `effective_scenario` (использованный сценарий со всеми правками) и `routes` — по одной записи `{t_s, client_id, path}` на каждую пару «отсчёт — клиентский пункт», `path` от пункта до шлюза, пустой — маршрута нет. Плюс `summary` по пунктам.
_Avoid_: экспорт, дамп, лог маршрутов

**Ссылка на конфигурацию**:
URL с `#c=<base64 дифф>`: встроенный сценарий + все правки относительно него; открытие ссылки восстанавливает конфигурацию.
_Avoid_: пермалинк, шаринг
