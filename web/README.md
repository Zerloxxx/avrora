# Аврора — прототип веб-сервиса

Статичный прототип (HTML/CSS/JS без сборки). Расчёт положений спутников,
ISL-связей и видимости с земли — порт `Расчетный модуль/geometry.py` на JS,
маршрут строится BFS-ом (минимум хопов) от клиентского пункта до шлюза.

3D-сцена — Three.js r160, Земля — текстуры NASA Blue Marble (4096px день, облака,
ночные огни, карта высот, блики океана). Библиотека и текстуры лежат в `vendor/`,
интернет для показа не нужен (кроме шрифтов Google Fonts — есть системный fallback).

Спутники — процедурная модель (корпус в ЭВТИ, панели солнечных батарей, тарелка в надир).
Чтобы подставить настоящую 3D-модель, положите glTF-файл в `vendor/satellite.glb` —
он подхватится автоматически и отмасштабируется.

## Запуск

```bash
python -m http.server 8765 --directory web
```

и открыть http://localhost:8765 (ES-модули не работают через `file://`).

## Тесты

```bash
node --test
```

23 теста проверяют расчётное ядро против эталона `geometry.py` (76 ISL-связей и маршрут C65 → S20 → G_MUR на t=0;
полное совпадение множества рёбер на 12:00 — если установлены Python и NumPy), сетку из 720 отсчётов,
доступность по сценариям, «липкую» маршрутизацию, валидацию файла и инструменты анализа.

## Рельеф вокруг пунктов (необязательно)

Маски горизонта для пунктов кейса и городов из списка уже посчитаны (`data/terrain.js`, ASTER GDEM 30 м). Пересчитать или добавить точку:

```bash
python web/tools/horizon-mask.py            # все пункты кейса и города → data/terrain.js
python web/tools/horizon-mask.py 71.64 128.87   # одна точка → JSON в stdout
```

Нужен интернет (OpenTopoData, ~1 запрос/с). В интерфейсе для любого пункта можно выбрать пресет местности
(посёлок / город / горная долина …) или запросить рельеф по кнопке (open-meteo, Copernicus DEM 90 м).

## Обновить встроенные сценарии

После изменения файлов в папке «Данные»:

```bash
python web/tools/bundle-scenarios.py
```

## Структура

- `index.html`, `style.css` — разметка и стили;
- `src/sim.js` — расчётное ядро (порт `geometry.py`): позиции, ISL, видимость с маской горизонта, маршрут, доступность,
  валидация, автоподбор, покрытие, N-1/N-2, Монте-Карло, резерв, Walker-генератор и подбор проекта; без DOM, работает в воркере и тестах;
- `src/model.js` — изменения конфигурации, варианты, импорт/экспорт, ссылка на конфигурацию;
- `src/scene.js` — Three.js: Земля, спутники, оверлей, камера, главный цикл;
- `src/panels.js` — боковые панели и окно сравнения;
- `src/analysis.js` — окно «Аналитика» и отчёт; `src/tools.js` + `src/worker.js` — фоновые расчёты;
- `src/state.js` — состояние, шина событий, хелперы; `src/app.js` — привязка событий и старт;
- `tests/` — тесты ядра (`sim.test.mjs` — эталон и ТЗ, `design.test.mjs` — рельеф и конструктор); `tools/` — сборка сценариев, маски рельефа; `data/` — встроенные сценарии и маски; `vendor/` — Three.js и текстуры.

Схема и поток данных — `../docs/ARCHITECTURE.md`; решения — `../docs/adr/`; термины — `../CONTEXT.md`.

## Демонстрационный сценарий (как повторить)

1. Открыть сайт → «Открыть проект». Сценарий «Полная группировка», пункт C65 — маршрут и причина перерыва видны в правой панели; таймлайн — внизу.
2. Этап развёртывания 3 → 1: доступность падает до 27 / 16 / 13 %.
3. «Конфигурация → Наземные пункты → Тикси → +»: первая очередь поднимается до 34 / 44 / 57 %.
4. Вернуть этап 3, «Анализ → Подобрать RAAN и фазу → Применить»: 96.7 % → 99.9 %. «Варианты → Сохранить», затем «сбросить всё», сохранить исходный, «Сравнить отмеченные».
5. Клик по спутнику на маршруте → период недоступности → «+»: маршрут перестраивается или появляется перерыв.
6. «Аналитика»: карта покрытия, план развёртывания, матрица N-1/N-2, Монте-Карло, «Сформировать отчёт».
7. «Выгрузить → Сценарий (JSON)», затем «Загрузить JSON» тот же файл — конфигурация восстанавливается.

## Что умеет

- сцена: реалистичная Земля с физически согласованным Солнцем (терминатор и ночные огни движутся со временем модели),
  атмосфера, орбиты, детализированные модели спутников, ISL-связи, наземные пункты; аппараты в тени Земли приглушены;
  вращение мышью, зум колесом или кнопками (от крупного плана аппарата до всей планеты);
- геометрия по правилам кейса плюс рельеф и застройка: маска горизонта пункта по 36 азимутам (пресеты местности,
  реальный DEM, своя), закрытые аппараты видны на сцене красным пунктиром;
- конструктор группировки: Walker T/P/F с веером RAAN 180°/360°, наклонение на плоскость («разные оси»), любое число
  и раскладка очередей запуска (плоскость за плоскостью или вперемешку); кейс = 48/3/1;
- подбор проекта (окно «Аналитика → Проект»): перебор ~200 Walker-конфигураций — минимум аппаратов для цели,
  фронт «число КА ↔ доступность», показатели первой очереди, «Применить» одним кликом;
- редактирование: этап развёртывания (кнопок столько, сколько очередей), RAAN, фазирование и наклонение каждой плоскости, периоды недоступности спутников и шлюза
  (клик по спутнику на сцене выбирает его для отказа), наземные пункты — добавление из списка городов, по координатам
  или кликом по Земле; сброс к исходному файлу;
- доступность за сутки по каждому пункту: диаграмма связи/перерывов, %, макс. перерыв, число перерывов, хопы,
  задержка сигнала, переключения маршрута; в панели — ближайшее окно связи;
- варианты: сохранение текущей конфигурации, повторное открытие, сравнение в таблице
  (изменённые параметры, показатели, дельты, рекомендация); хранятся в localStorage;
- аналитика (окно «Аналитика», расчёты в воркере):
  - карта покрытия 55–85° с.ш. (сетка 2.5°×5°) с наложением на глобус;
  - план развёртывания по этапам/месяцам и подбор состава очередей запуска;
  - матрица отказов N-1/N-2 и запас прочности, Монте-Карло случайных отказов, поиск места для резервного аппарата;
  - качество связи: задержка, переключения, геометрическая видимость, режим «в тени ISL выключены»;
  - отчёт «Обоснование конфигурации» (HTML, печать в PDF);
- инструменты панели: автоподбор RAAN/фазы, поиск самых уязвимых аппаратов;
- выгрузка: изменённый сценарий (схема `cosmo-A-1.0`), результат расчёта по схеме `cosmo-A-result-1.0`
  (`effective_scenario` + `routes` на каждую пару «отсчёт — пункт» + сводка), варианты, ссылка на конфигурацию;
- работает на телефоне, планшете и ноутбуке: панели-шторки, меню, щипок для зума, модальные окна во весь экран;
- кнопка с часами — перейти к текущему времени UTC;
- загрузка своего JSON со списком ошибок, если файл некорректен.
