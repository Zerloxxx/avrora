Орбитальные плоскости

RAAN, °Фаза, °Накл., °КА

RAAN поворачивает плоскость, фаза сдвигает аппараты вдоль орбиты, наклонение — «ось» плоскости (по умолчанию общее). Пересчёт — сразу после ввода.

Конструктор группировки

Walker T/P/F: T аппаратов поровну в P плоскостях, F задаёт сдвиг фаз между плоскостями. Кейс — 48/3/1, веер 180°. RAAN и фаза задаются при выводе (окно старта, довыведение); один запуск — одна плоскость, поэтому очередь «по нескольким плоскостям» = несколько запусков. Заменяет текущую группировку; отказы по несуществующим аппаратам снимаются.

Аналитика

Подбор группировки под заданные пункты: перебор Walker-конфигураций (число аппаратов, плоскостей, фазирование, веер RAAN, наклонение) с теми же правилами расчёта. Показывает, сколько аппаратов минимально нужно для цели и что даёт каждая следующая партия.

КА: плоскостей: очередей:

Доля времени со сквозным маршрутом до шлюза для сетки точек 55–85° с.ш. (шаг 2.5° × 5°). Показывает, где группировка сильная, а где дыры — не только для трёх пунктов из задания.

Запуски с интервалом три месяца: какую связь получат пункты на каждом этапе, и можно ли улучшить ранние этапы другим составом очередей. Число и размер очередей — из конструктора группировки.

Что случится при отказах: матрица N-1/N-2 по всем парам аппаратов, запас прочности, вероятностная оценка и лучшее место для резервного спутника.

% отказов/сутки · прогонов

Доступность ≠ хорошая связь. Задержка сигнала по длине маршрута, число переключений маршрута за сутки, чисто геометрическая видимость и влияние тени Земли.

Как это работает

Задача. 48 спутников на высоте 550 км должны обеспечить связь северных наземных пунктов со шлюзом в Мурманске. Данные идут по цепочке «пункт → спутник → … → спутник → шлюз». Цель — сквозной маршрут не менее 90% времени для каждого пункта.

Расчёт. Каждые 120 с за сутки вычисляются положения аппаратов (круговые орбиты, вращение Земли), видимость с пунктов (угол возвышения ≥ 10°) и межспутниковые связи (дальность ≤ ISL и линия не пересекает Землю). Формулы — из расчётного модуля кейса. Сверх кейса: у пункта может быть маска горизонта — закрытие неба рельефом или застройкой по 36 азимутам (пресеты местности, реальный рельеф ASTER/Copernicus DEM, своя); аппарат виден, только если он выше и минимального угла, и маски в своём азимуте.

Маршрут. Поиск в ширину по графу «спутники + связи»: клиент подключается к любому видимому аппарату, маршрут заканчивается на аппарате, видимом со шлюза. Клиентские пункты не ретранслируют. Если маршрута нет — сервис называет причину: нет видимого спутника, разрыв сети, нет контакта со шлюзом или шлюз недоступен.

Показатели. По каждому пункту: доля отсчётов с видимым активным спутником, доля отсчётов с маршрутом до шлюза (доступность), максимальный перерыв, число перерывов, среднее число переходов маршрута (рёбер, включая две наземные линии), задержка, переключения. Сетка — 720 отсчётов 0…86 280 с, как в описании данных.

Проектирование. Конструктор группировки собирает Walker T/P/F (T аппаратов в P плоскостях, фазирование F, веер RAAN 180° или 360°), даёт каждой плоскости своё наклонение и раскладывает аппараты по любому числу очередей запуска; кейс — 48/3/1 с веером 180°. «Подбор проекта» перебирает ~200 таких конфигураций и показывает минимум аппаратов для цели и что даёт каждая следующая партия.

Инструменты. Автоподбор RAAN и фазирования — покоординатный спуск по плоскостям, целевая функция: сначала худший пункт, затем перерывы и хопы. Поиск уязвимых аппаратов — по очереди выводим каждый спутник на сутки и смотрим, у кого просадка сильнее.

Аналитика. Карта покрытия — та же модель для сетки точек всего Севера. План развёртывания — расчёт по этапам и жадный подбор состава очередей. Устойчивость — полный перебор одиночных и парных отказов, Монте-Карло случайных отказов, поиск слота для резервного аппарата. Маршрут «липкий»: держится, пока все его звенья существуют, — так считаются переключения и задержка.

Ограничение модели. Орбита на сцене приподнята визуально (×1.42), чтобы спутники читались; все расчёты идут в настоящих километрах.
