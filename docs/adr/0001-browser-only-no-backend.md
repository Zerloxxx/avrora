# ADR-0001: Расчёт в браузере, без бэкенда

Status: accepted
Date: 2026-09-11

## Context
ТЗ оставляет стек на усмотрение команды, но требует: сервис доступен жюри через браузер, жюри загружает свой JSON и меняет параметры, результат выгружается. Хакатон — сроки короткие, хостинг с бэкендом нужно кому-то поддерживать во время проверки. Полный расчёт суток (721 шаг × 48 аппаратов) на JS занимает ~20 мс — сервер для этого не нужен.

Рассмотрено: (а) Python-бэкенд с `geometry.py` + тонкий фронтенд; (б) всё в браузере, `geometry.py` портируется на JS.

## Decision
Вариант (б). Ядро — `web/src/sim.js`, порт `geometry.py` один в один по формулам; тяжёлые переборы — в Web Worker. Хостинг — любая статика.

## Consequences
- Нет сервера → нет падений во время проверки, нет ключей и секретов, ссылка живёт вечно.
- Расчёты дублируют эталонный модуль на другом языке → обязателен тест на совпадение с `geometry.py` (76 ISL на t=0, маршрут C65→S20→G_MUR).
- Ограничение: очень тяжёлые переборы (N-2 при 48 КА ≈ 5–8 с) идут на машине жюри; при росте группировки до сотен аппаратов решение придётся пересматривать.
