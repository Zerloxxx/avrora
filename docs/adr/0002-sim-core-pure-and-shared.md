# ADR-0002: Ядро — чистые функции, общие для UI, воркера и тестов

Status: accepted
Date: 2026-09-12

## Context
Критерии жюри: «разделение расчётной логики и интерфейса, возможность проверить ключевые функции». Первый прототип держал расчёт и рендер в одном файле; появление воркера и тестов потребовало выделить ядро.

## Decision
`sim.js` не импортирует ничего и не знает про DOM/state. Он принимает `scenario` и параметры, возвращает данные. Один и тот же модуль импортируется интерфейсом (быстрые расчёты), `worker.js` (тяжёлые) и `node --test`.

Интерфейс разделён на модель (`model.js` — единственное место мутаций `state`, публикует события) и представления (`panels.js`, `analysis.js`, `scene.js` — только читают `state`). Связь через шину событий в `state.js`, чтобы модули не импортировали друг друга по кругу.

## Consequences
- Любая новая аналитика = функция в `sim.js` + строка в `worker.js` + рендерер; ядро тестируется без браузера.
- Цена: события вместо прямых вызовов — порядок перерисовки задаётся подписками, а не последовательностью кода; при отладке смотреть таблицу событий в `docs/ARCHITECTURE.md`.
