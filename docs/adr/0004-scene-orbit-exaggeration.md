# ADR-0004: Орбита на сцене приподнята в 1.42 раза

Status: accepted
Date: 2026-09-11

## Context
Реальная высота 550 км — 8.6% радиуса Земли: спутники в масштабе сливаются с поверхностью и атмосферным ободом, орбиты не читаются.

## Decision
В сцене радиус орбиты = 1.42 радиуса Земли (`ORBIT_VISUAL` в `scene.js`); все расчёты — в настоящих километрах, проекция на экран для подписей делается через ту же приподнятую позицию. Ограничение написано в окне «О подходе» и в отчёте.

## Consequences
- Картинка читаема; ISL-линии и маршрут визуально совпадают с расчётом, потому что рёбра берутся из `snapshot`, а не из геометрии сцены.
- Углы возвышения «на глаз» по сцене оценивать нельзя — только по цифрам.
