# ADR-0006: Сценарии кейса встроены в data/scenarios.js

Status: accepted
Date: 2026-09-11

## Context
Четыре JSON из папки «Данные» нужны при старте без запросов и без CORS-проблем на любом хостинге (в том числе там, где статика раздаётся с другого origin).

## Decision
`tools/bundle-scenarios.py` собирает их в `window.SCENARIOS`; интерфейс читает только этот объект. Свои файлы жюри грузит через «Загрузить JSON» с валидацией (`validate()` — порт проверки из `geometry.py`, ошибки словами).

## Consequences
- Изменил «Данные» → обязан пересобрать (`python web/tools/bundle-scenarios.py`); чеклист в `CLAUDE.md`.
- Ссылка на конфигурацию (`#c=`) кодирует дифф относительно встроенного сценария — для загруженных вручную файлов ссылка не работает (id `__custom__`).
