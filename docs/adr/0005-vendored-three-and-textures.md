# ADR-0005: Three.js и текстуры Земли лежат в репозитории

Status: accepted
Date: 2026-09-11

## Context
Демо на защите и проверка жюри могут проходить без стабильного интернета; CDN и внешние текстуры — точка отказа. Сборщик (Vite и т. п.) добавил бы шаг установки для жюри.

## Decision
`web/vendor/`: `three.module.js` r160, `GLTFLoader`, `RoomEnvironment`, текстуры NASA Blue Marble из репозитория three.js (4096 день, 2048 облака/огни/рельеф/блики). Подключение через `importmap`, без сборки. Google Fonts — единственная внешняя зависимость, с системным fallback.

## Consequences
- +8 МБ в репозитории (один раз); обновление three — ручная замена файла.
- Сайт открывается любым HTTP-сервером; `file://` не работает из-за ES-модулей — для этого есть `start.bat`/`start.sh`.
